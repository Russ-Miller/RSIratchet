# M58 — Reconcile the heuristic-first UI

## Intent and archaeology

Russ requested a cohesive UI that preserves the earlier Codex redesign while
reconciling subsequent Claude work. The October 20 rework report and decision
log establish the intended shift: a shared reasoning bank for agents, with
practical heuristics leading and capabilities, claims, techniques, and sources
providing supporting depth. Failures and scope conditions remain visible.
The visual direction is warm paper, green accents, sans-serif body type, and
restrained serif notes. Accounts and automated agent write-back remain future work.

The October 21–24 decisions extend that direction with paper discovery,
selected-section session reviews, candidate curation, and separate claim-admission
and heuristic-promotion gates. These are compatible additions, not reasons to
return to the personal-study experience.

The homepage, styling, and candidate workbench were already present as local
uncommitted changes on `content-licensing-freshness`. Git and the reports do not
establish which assistant authored every change, or prove that a particular
redesign was reverted. The old UI is not wholly lost.

## Reconciliation

- Added `/research` as a broad evidence overview. Research previously linked
  only to `/ratchet`, a narrower collection about learning loops.
- Added shared research navigation to the evidence indexes and learning-loop
  collection. The main Research link stays active on evidence detail routes.
- Unified index headings, warm neutral utilities, navigation, selected filters,
  and table surfaces with the existing design. Dark metadata uses the shared
  muted color; mobile navigation/filter targets and search font sizes improved.
- Contained wide sources/capabilities tables in labeled, keyboard-focusable
  scroll regions. Cards and candidate controls accommodate narrow layouts.
- Moved the homepage applicability note after the useful principles, retaining
  its substance. Corrected the capabilities card to count capability topics.
- Added a candidate breadcrumb and updated the About page to acknowledge the
  existing candidate workbench. Sources no longer say “my own observations.”
- Retained candidate evidence, review scope, failure conditions, and the
  distinction between author testing, human review, and independent replication.
- Corrected list search so semantic matches stay in their respective source
  sections and clearing search restores each section's original order.
- Updated the spec's obsolete migration status and documented the navigation
  hierarchy to reduce future cross-session drift.

Catalog records, discovery results, licensing choices, API behavior, and agent
submission permissions are preserved. No new dependencies or external model
calls were introduced.
