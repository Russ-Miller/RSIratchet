- **Sweep a bounded replanning budget before extending recovery** (author-tested): For a tool-orchestration harness with execution verification, measure the success-versus-cost curve over a few replanning rounds instead of allowing open-ended retries.

## arxiv-2609-03718

Selected CAE ablations separate domain information from added reflection, with strong limitations from model and benchmark comparisons.

- **Test direct domain tutorials before building a specialized scaffold** (author-tested): For simulation agents lacking solver-specific idioms, compare direct relevant tutorials with optional or absent tutorials before investing in additional retrieval orchestration.
- **Measure the marginal value of scripted reflection** (author-tested): When a coding harness already supplies execution feedback and repair attempts, compare an added self-reflection instruction with the unchanged harness before retaining it.
