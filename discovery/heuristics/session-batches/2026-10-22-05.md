# Codex session batch 05

Reviewed selected sections of 3 papers; 5 proposals. These are partial reviews, not independent validation. No separately billed inference calls.

## arxiv-2405-15793

Selected interface ablations support search-result presentation and edit guardrails; observational trajectory correlations are not promoted into causal stopping rules.

- **Test compact search results against iterative match browsing** (author-tested): For repository-repair agents, compare a compact search interface with interfaces that require opening matches one at a time; measure tool-call and context overhead as well as fix rate.
- **Reject syntax-breaking edits with immediate feedback** (author-tested): For repository repair, test an editor that checks proposed modifications for major syntax errors before applying them and returns actionable feedback when rejecting an edit.

## arxiv-2407-01489

The paper motivates a simpler staged baseline, with explicit limits from unmatched models, budgets and issue difficulty.

- **Include a staged repair pipeline before adding autonomous orchestration** (inferred): When choosing a repository-repair harness, benchmark a fixed localization, repair and validation pipeline alongside autonomous tool orchestration.

## arxiv-2406-12045

Selected method comparisons and consistency analysis support native tool-calling tests and repeated-trial evaluation.

- **Compare native tool calling with text-formatted action protocols** (author-tested): For user-facing tool agents whose model supports native function calling, compare that interface with text-formatted ReAct before adding textual reasoning machinery.
- **Measure all-trial reliability alongside average agent success** (inferred): For customer-service agents, repeat each evaluation task and report the fraction consistently solved across trials alongside average one-run success.
