## arxiv-2609-14758

Selected setup and defense comparisons support an explicit unusable-result branch, with limitations from stub tools and model judging.

- **Give unusable tool results an explicit failure branch** (author-tested): When an agent answers from tool output, require it to check whether the requested value is usable and explicitly declare retrieval failure before answering when it is not.

## arxiv-2609-19425

Selected resolver comparisons support membership-plus-signature checks, with important limits on honest over-rejection and semantic correctness.

- **Resolve tool identity and signature before execution policy** (author-tested): For raw-JSON or merged MCP tool calls, check the live registry identity and declared argument signature before applying action policy or dispatching the call.

## arxiv-2609-18304

Selected recovery ablations support retaining failure knowledge while restoring executable state.

- **Retain failure lessons when restoring a prior agent state** (author-tested): For reversible long-horizon tasks, compare rollback with persistent structured reflection against rollback-only and reflection-only recovery.
