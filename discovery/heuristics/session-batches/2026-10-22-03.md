# Codex session batch 03

Reviewed selected sections of 3 papers; 5 proposals. These are partial reviews, not independent validation. No separately billed inference calls.

## arxiv-2404-06654

Selected RULER results support task-sensitive context evaluation; the recommendation is inferred from benchmark failures, not a tested production routing policy.

- **Measure usable context on more than a single retrieval needle** (inferred): Before setting a harness context budget, test retrieval, multi-hop tracing and aggregation at representative lengths and task complexities, then confirm on the actual workload.

## arxiv-2410-10813

Selected methods and ablations support reader-dependent context budgets, fact-augmented indexing and qualified temporal filtering.

- **Tune retrieved-token budgets to the reader** (author-tested): When building conversational memory, sweep the retrieved-token budget separately for each reader model instead of maximizing retrieved context by default.
- **Augment memory keys with facts while retaining original evidence** (author-tested): For conversational-memory retrieval, compare indexing the original round plus extracted user facts with indexing only compressed facts; keep original text available to the reader.
- **Validate time-range extraction before filtering memory** (author-tested): For time-sensitive memory queries, test event-date indexing and query-derived time filters only with a model that can reliably infer the required date range.

## arxiv-2602-11988

Inspected comparisons support evaluating context-file cost and usefulness rather than assuming generated repository overviews improve task success.

- **Evaluate repository instructions as a cost-bearing intervention** (author-tested): Before adding automatically generated repository context, compare it with the existing instructions on task completion and inference cost; include only guidance whose practical value is demonstrated.
